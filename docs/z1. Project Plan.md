### 🧱 2. Core Modules (Mirroring C# Structure)

| Module      | Purpose                                                                                 |
|-------------|-----------------------------------------------------------------------------------------|
| `roles/`    | Enum-like definitions for `AuthorizeRoleEnum`                                           |
| `claims/`   | Enum + utilities for `AuthorizeClaimEnum`, `ClaimType`, `ClaimPriority`                 |
| `policies/` | `PolicyEnum`, `GroupPolicyEnum`, and mapping logic                                      |
| `services/` | `PolicyAuthorizationService` with async methods for role/claim validation                   |
| `filters/`  | Express middleware equivalents for `PolicyAuthorizeAttribute`, `ClaimAuthorizeAttribute`|
| `resource/` | Handlers for `ResourceManagerAuthorization` and `ResourceOwnerAuthorization`            |
| `dynamic/`  | `MinimumAgeAuthorize` and `MinimumAgePolicyProvider`                                    |
| `identity/` | Session claim management (`SignInClaim`), token providers (email/phone)                 |
| `di/`       | Registration helpers for Express, NestJS, or other frameworks                           |
